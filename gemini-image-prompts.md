# Hainholt — Gemini product photo prompts

Paste these into Gemini's image generation (Nano Banana) one at a time, in a fresh
message each time so details don't blend between shots. Generate square (1:1),
at the largest size available — GMC wants at least 800x800px, ideally 1500x1500px.

Save each result using the filename noted under each product so it matches
`src/data/products.json`. Once you have them, send them over (or the folder
they're in) and I'll wire the real photos into the site and drop the placeholders.
